# Challenge Amigo Secreto

Desafio de código do programa ONE (Oracle Next Education), da Alura com a Oracle. A página permite adicionar os nomes dos participantes numa lista e sortear um amigo secreto.

## Funcionalidades

- Adiciona nomes à lista de participantes
- Sorteia um nome da lista e mostra o resultado na tela

## Tecnologias

HTML, CSS e JavaScript.

## Como abrir

Basta abrir o `index.html` no navegador.
